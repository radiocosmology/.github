# Contributing to `radiocosmology`

This document describes the requirements for contributing to repos in the `radiocosmology`
organisation.

## AI Usage

The most important rule: **you must understand your code**. Do not create a pull request
unless you can explain what your changes do and why without the help of an AI agent. Please 
see the [AI Usage Policy](AI_POLICY.md) for full information.

## Pull Requests

Pull requests should only address a single bug, feature, or task. Do **not**:

- Include changes or bug fixes unrelated to the main PR topic (such as those found
  using an AI agent). Put them in a separate PR.
- Include automatic formatting/style changes from tools like `ruff` or `black` in an
  unrelated PR. These should also go in their own PR.
